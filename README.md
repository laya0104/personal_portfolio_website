# Personal Portfolio Website

A responsive personal portfolio website developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Features
- Responsive design
- About, Skills, Projects, and Contact sections
- Contact form with MongoDB database integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## How to Run
1. Navigate to the backend folder.
2. Run `npm install`.
3. Add your MongoDB connection string in a `.env` file.
4. Run `node server.js`.
5. Open `frontend/index.html` in your browser.
